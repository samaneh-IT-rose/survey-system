# سامانه فرم نظرسنجی تلفنی

سامانه وب فارسی (راست‌به‌چپ) برای ثبت، ویرایش، گزارش‌گیری و تحلیل فرم‌های نظرسنجی تلفنی — بر پایه سند اجرایی تأییدشده.

**بک‌اند:** Python + FastAPI · **دیتابیس:** PostgreSQL · **رابط کاربری:** HTML/CSS/JS راست‌به‌چپ با قالب‌های Jinja2 · **نمودارها:** Apache ECharts (میزبانی محلی) · **PDF:** Playwright/Chromium

---

## امکانات

| قابلیت | توضیح |
|---|---|
| ثبت فرم | فرم فارسی واکنش‌گرا با اعتبارسنجی سمت مرورگر **و** سرور |
| ویرایش رکورد | بازکردن رکورد ذخیره‌شده با `?id=شماره` و ویرایش امن |
| آرشیو | جست‌وجو (نام/کد ملی/تلفن)، فیلتر استان/شهرستان/وضعیت تماس/بازه تاریخ شمسی، صفحه‌بندی |
| خروجی اکسل | فایل XLSX راست‌به‌چپ با ستون‌های پویا مطابق سؤال‌های فعال |
| خروجی PDF | دقیقاً یک صفحه A4، تولید سمت سرور با قالب چاپ مستقل |
| چاپ | نمای چاپ A4 با دکمه چاپ (چاپ در مقیاس ۱۰۰٪ روی کاغذ A4) |
| داشبورد | شاخص‌های کلیدی، نمودار فراوانی هر سؤال (با «بدون پاسخ» جداگانه)، وضعیت تماس، برترین استان‌ها، روند روزانه — همه با فیلتر |
| تم‌های رنگی | حالت روز/شب + ۴ پالت (صورتی سازمانی، آبی، سبز، بنفش) با ذخیره ترجیح کاربر؛ تم روی چاپ/PDF اثر نمی‌گذارد |
| مدیریت الگوی فرم | افزودن/ویرایش/ترتیب/فعال‌سازی سؤال‌ها و وضعیت‌های تماس بدون تغییر کد |

## قواعد پیاده‌سازی‌شده مطابق سند

- **کد ملی:** الگوریتم دوم سند (بخش ۵) — پذیرش ۸ تا ۱۰ رقم، تبدیل ارقام فارسی/عربی، تکمیل صفر ابتدایی، رد ارقام تکراری و خط تیره/فاصله داخلی؛ ذخیره به‌صورت رشته.
- **تاریخ شمسی:** انتخابگر جلالی در مرورگر؛ کنترل روز نامعتبر، طول ماه و **سال کبیسه در سرور**؛ ذخیره در ستون `DATE` میلادی و نمایش شمسی `۱۴۰۵/۰۸/۰۵`؛ زمان ثبت/ویرایش با منطقه زمانی تهران.
- **استان/شهرستان:** کمبوباکس وابسته؛ با تغییر استان، شهرستان قبلی پاک می‌شود؛ ارتباط در بک‌اند نیز کنترل می‌شود (درخواست مستقیم ناهمخوان پذیرفته نمی‌شود).
- **جدول نظرسنجی:** برای هر ردیف فقط یک گزینه (رفتار رادیویی با ظاهر تیک‌مانند)؛ کلیک روی عنوان گزینه همان گزینه را انتخاب می‌کند.
- **وضعیت تماس:** تک‌انتخابی؛ اگر وضعیت «نیازمند تکمیل جدول» نباشد، جدول غیرفعال می‌شود و پاسخ خالی جداگانه گزارش می‌گردد — هیچ پاسخ خالی بی‌صدا به «متوسط» تبدیل نمی‌شود.
- **پاک‌کردن/فرم جدید:** فقط فرم جاری را خالی می‌کند و دیتابیس را تغییر نمی‌دهد؛ در صورت وجود تغییر ذخیره‌نشده، تأیید گرفته می‌شود.
- **پاسخ‌ها و الگو:** متن پرسش هنگام ثبت در پاسخ snapshot می‌شود؛ ویرایش متن الگو معنای پاسخ‌های قدیمی را تغییر نمی‌دهد. متن‌ها به‌صورت امن (escape شده) رندر می‌شوند.
- **امنیت پایه:** اطلاعات اتصال دیتابیس فقط در متغیر محیطی/سرور است؛ پیام خطای استاندارد بدون افشای جزئیات سرور؛ کوئری‌های پارامتری با SQLAlchemy.

```
│   │   ├── jalali.py            # تبدیل/اعتبارسنجی تاریخ شمسی

│   ├── services/
│   │   ├── validation.py        # اعتبارسنجی کامل سمت سرور
│   │   ├── dashboard.py         # محاسبات آماری داشبورد
│   │   ├── excel_export.py      # خروجی XLSX
│   │   ├── pdf_export.py        # تولید PDF با Playwright
│   │   └── sheet.py             # زمینه مشترک ورقه A4
│   ├── routers/                 # APIها و صفحات
│   ├── templates/               # قالب‌های Jinja2 (sheet.html = قالب چاپ/PDF)
│   └── static/                  # css, js, فونت وزیرمتن, echarts, لوگو
├── requirements.txt
```

## راه‌اندازی

```bash
# ۱) دیتابیس (PostgreSQL 16 portable — بدون نیاز به دسترسی مدیر)
bash scripts/setup_postgres.sh          # در صورت نبود سرویس، نمونه داخلی را بالا می‌آورد

# ۲) وابستگی‌ها
pip install -r survey-system/requirements.txt
playwright install chromium             # فقط بار اول برای PDF

# ۳) داده اولیه (استان‌ها، سؤال‌ها) + رکورد نمونه اختیاری
python scripts/seed.py --demo 40

# ۴) اجرای بک‌اند (پورت 3030)
bash scripts/start_survey.sh
```

رابط کاربری از مسیر `/app/` (پروکسی‌شده از پورت 3000) در دسترس است. مستندات OpenAPI: `/docs`.

### متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `SURVEY_DATABASE_URL` | `postgresql+psycopg2://survey:survey@127.0.0.1:5432/surveydb` | نشانی دیتابیس |
| `SURVEY_ORG_NAME` | `نام سازمان` | نام سازمان در سربرگ‌ها |
| `SURVEY_LOGO_URL` | `/app/static/logo/logo.svg` | نشانی لوگو |
| `SURVEY_SELF_URL` | `http://127.0.0.1:3030` | نشانی خود سرویس برای رندر PDF |

## پشتیبان‌گیری و بازیابی

```bash
# پشتیبان‌گیری
/home/z/.venv/lib/python3.12/site-packages/pgserver/pginstall/bin/pg_dump \
  -h 127.0.0.1 -U survey -d surveydb -Fc -f backup.dump

# بازیابی
.../pg_restore -h 127.0.0.1 -U survey -d surveydb --clean backup.dump
```

## جایگزینی اقلام در انتظار تأیید سفارش‌دهنده

- **متن سؤال‌ها و وضعیت‌های تماس:** از فایل Word — بدون تغییر کد از صفحه «مدیریت الگو» اصلاح می‌شود.
- **فهرست استان/شهرستان:** فهرست فعلی «نمونه» است؛ پس از دریافت Excel رسمی با همان ساختار جدول‌های `provinces`/`counties` جایگزین می‌شود.
- **لوگو:** فایل `app/static/logo/logo.svg` (یا مسیر `SURVEY_LOGO_URL`) با لوگوی رسمی جایگزین شود.
- **رنگ سازمانی:** پالت صورتی از لوگوی رسمی استخراج و در `static/css/styles.css` (بخش متغیرها) تنظیم می‌شود.
- **ورود اطلاعات از فایل (Excel/CSV):** طبق سند (بخش ۱۱) قابلیت مرحله بعدی است و پس از دریافت نمونه فایل اضافه می‌شود.
- **نقش‌ها و ورود کاربران:** برای نسخه اولیه تک‌کاربره طراحی شد؛ جدول‌های `users`/`audit_logs` فاز بعد (بخش ۱۵ سند).

## عیب‌یابی سریع

| نشانه | راهکار |
|---|---|
| خطای اتصال دیتابیس | `bash scripts/setup_postgres.sh` را اجرا و وضعیت را با `pg_isready -h 127.0.0.1 -p 5432` بررسی کنید |
| صفحه `/app` باز نمی‌شود | لاگ: `logs/survey-server.log` — در صورت توقف، `bash scripts/start_survey.sh` |
| PDF ساخته نمی‌شود | `playwright install chromium` را اجرا کنید |
| تاریخ ۳۰ اسفند رد می‌شود | درست است؛ کنترل کبیسه در سرور فعال است |
| فونت فارسی در PDF ناخوانا | فونت‌های وزیرمتن در `app/static/fonts` و `~/.local/share/fonts` نصب‌اند؛ `fc-cache -f` اجرا کنید |
